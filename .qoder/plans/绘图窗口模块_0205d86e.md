# 绘图窗口模块

## 一、交付范围确认

- 形态：独立可执行 `notework-doodle`，复用现有 GTK4 + libadwaita + Cairo + GResource 技术栈。
- 图层：仅搭骨架（doodle 层 + 占位 image 层），图片加载/渲染留接口，不实现。
- 阵列：作为整体组（选中/拖动/删除按组操作），但组内副本仍占用各自编号。
- 编号：画布上贴编号 + 右侧面板列出全部编号与缺号提示，支持手动改号。

## 二、文件与构建结构

新增文件（均放在 `src/`）：

- `doodle.h` — 公共类型（Shape/ShapeKind/Layer/Tool）与跨模块函数原型。
- `doodle_model.c` — 数据模型：Shape 增删、编号分配、擦除分裂、阵列展开/提交、缺号扫描。
- `doodle_canvas.c` — `GtkDrawingArea` 渲染回调与指针/手势事件处理（直线、路径、擦除、选择、阵列预览拖动）。
- `doodle_window.c` — 组装窗口：左侧画布 + 右侧面板（工具按钮 + 编号列表 + 阵列参数 + 图层列表）。
- `doodle_main.c` — `AdwApplication` 入口（独立调试程序）。
- `doodle_window.ui` — GtkBuilder 骨架（HeaderBar、Paned、SpinButton、ListView 等）。
- `doodle_row.ui` — 编号列表行模板（编号 + 类型图标 + 可编辑数字 + 删除按钮）。

修改：

- `meson.build` 增加 `executable('notework-doodle', ...)`，源文件包含上述 .c 与新的 resources 目标。
- `src/notework.gresource.xml` 新增 `doodle_window.ui` / `doodle_row.ui`（或新建 `doodle.gresource.xml` 单独编译，避免污染主程序资源；推荐后者）。
- `src/style.css` 追加 doodle 专用类（`.doodle-canvas`、`.layer-row` 等）。

不动 `main.c` / `window.ui` / `row.ui`，主程序行为不变。

## 三、数据模型（`doodle.h` / `doodle_model.c`）

```c
typedef enum { SHAPE_LINE, SHAPE_PATH, SHAPE_ARRAY } ShapeKind;
typedef struct { double x, y; } DPoint;

typedef struct Shape {
    ShapeKind kind;
    int       number;          // 全局编号，1..N，可被用户改写造成空缺
    double    dx, dy;          // 累积平移（整组也用这一对）
    union {
        struct { DPoint a, b; } line;
        struct { DPoint *pt; size_t n, cap; } path;
        struct {
            struct Shape *base;        // 阵列基准（克隆，独立坐标）
            int    rows, cols;
            double gap_x, gap_y;
            int   *child_numbers;      // 长度 rows*cols，行优先（上→下，左→右）
        } arr;
    };
} Shape;

typedef struct {
    Shape **items; size_t n, cap;     // 顺序 = 绘制叠放顺序
} ShapeStore;
```

图层（骨架）：

```c
typedef enum { LAYER_DOODLE, LAYER_IMAGE_STUB } LayerKind;
typedef struct { LayerKind kind; gboolean visible; char *name; /* image 留 GdkTexture* tex; */ } Layer;
```

`DoodleDoc` 持有 `GArray<Layer>` 与每个 doodle 层各自的 `ShapeStore`。本阶段默认创建一个 doodle 层在最上方，UI 上提供"在下方插入图片图层"按钮，仅创建 LAYER_IMAGE_STUB 占位。

## 四、编号系统

规则：

- 每次创建直线 / 路径 / 阵列副本，调用 `model_alloc_number()`：取当前最大编号 + 1（自动操作下保持紧凑 1..N）。
- 阵列提交：基准 base 释放原编号，组内 `rows*cols` 个副本按行优先连续分配编号；删除整组时，回收这一整段并对所有大于段尾的编号 -k 补位。
- 擦除分裂路径：在 `model_split_path_at()` 中，命中段把原路径切成 ≥1 条新路径，第一段沿用原编号，其余段在原编号紧后插入并把后续所有图形编号顺移 +k，保持紧凑且尊重原次序。
- 删除任意 Shape：把该编号之后的所有图形编号 -1，UI 同步刷新。
- 用户改号：`model_set_number(shape, new)` 直接写入；不自动整理，允许出现空缺/重复。重复时 UI 标红提示。
- 缺号扫描：`model_missing_numbers(out_array)` 扫描 1..max(number)，返回缺失序列；右侧面板顶部显示如 `缺号: 5, 9-11`。

## 五、画布与工具状态机（`doodle_canvas.c`）

`GtkDrawingArea` + `gtk_drawing_area_set_draw_func()`，事件用 `GtkGestureClick` / `GtkGestureDrag` / `GtkEventControllerMotion`。

工具枚举：`TOOL_LINE / TOOL_PATH / TOOL_ERASE / TOOL_SELECT / TOOL_ARRAY_PREVIEW`。

- 直线：按下记 a，拖动实时显示橡皮筋，释放写入 Shape。
- 路径：按下开始记录点，拖动追加（间距阈值 ≥1px 去抖），释放结束。
- 擦除：拖动时维护一个圆形擦除头，命中线段做几何裁剪 → 调用 `model_split_*` 重排编号。
- 选择：单击命中测试（路径用折线段距离阈值，直线同理，阵列组用整体包围盒）。命中后显示选中框，拖动改动 `dx/dy`。
- 阵列预览：在选中一个图形（非组）时点击"阵列"按钮 → 进入预览态。右侧面板的 rows/cols/gap_x/gap_y SpinButton 实时改动；预览期间用半透明绘制副本，可整体拖动调整位移；点"应用"提交为 `SHAPE_ARRAY` 并完成编号；点"取消"丢弃。

绘制流程（`canvas_draw`）：

1. 自底向上遍历 layers：image stub 层留空。
2. doodle 层：遍历 ShapeStore，按 kind 调 cairo 绘制；阵列组依据 base 几何 + (i,j) 偏移渲染 rows*cols 次。
3. 在每个图形锚点（直线起点 / 路径首点 / 阵列每个副本首点）旁绘制编号文本。
4. 选中态画包围盒；阵列预览态画半透明副本与红色应用/取消热区（也通过面板按钮触发）。

## 六、UI（`doodle_window.ui`）

- `AdwApplicationWindow` → `AdwToolbarView`
  - top: `AdwHeaderBar`，end 放工具切换 `GtkToggleButton` 五枚（直线/路径/擦除/选择/阵列）。
  - content: `GtkPaned` 水平分割
    - 左：`GtkScrolledWindow` 包 `DoodleCanvas`（自定义控件，C 中通过 `g_object_new(GTK_TYPE_DRAWING_AREA, ...)` 即可，无需 GObject 子类化）。
    - 右：`GtkBox` 垂直，含：
      - 缺号提示 Label（`.warn` 样式）。
      - 编号 `GtkListView`（绑定到模型，行模板 `doodle_row.ui`：编号 SpinButton 可改 + 类型 + 删除按钮）。
      - 分隔。
      - 阵列参数面板：rows/cols/gap_x/gap_y 四个 `GtkSpinButton` + "应用" / "取消" 按钮。
      - 分隔。
      - 图层列表（简单 `GtkListBox`）+ "在下方插入图片图层" 按钮（仅创建占位）。

## 七、对外集成接口

`doodle.h` 暴露：

```c
GtkWidget *doodle_window_new(void);            // 独立窗口
GtkWidget *doodle_view_new(void);              // 内嵌视图（左 paned 内容），后续主程序集成用
DoodleDoc *doodle_view_get_doc(GtkWidget *v);
```

`doodle_main.c` 仅调 `doodle_window_new()`。后续若要嵌入主窗口，只需在主 `window.ui` 加按钮调用同一函数或 `doodle_view_new()`。

## 八、构建改动（`meson.build` 关键片段）

```meson
doodle_resources = gnome.compile_resources(
  'doodle-resources',
  'src/doodle.gresource.xml',
  source_dir : 'src',
  c_name : 'doodle',
)

executable('notework-doodle',
  sources : ['src/doodle_main.c', 'src/doodle_window.c',
             'src/doodle_canvas.c', 'src/doodle_model.c',
             doodle_resources],
  dependencies : [gtk4_dep, adw_dep],
  install : true,
)
```

主 `notework` 目标不变。

## 九、不在本阶段范围

- 图片解码 / 加载 / 缩放（仅留占位层与接口）。
- 撤销 / 重做、剪贴板、文件保存与加载。
- 阵列内部副本的单独编辑（按选择"整组"语义，组内不可单独擦除/拖动副本）。
- 与主窗口的真正集成（仅暴露 `doodle_window_new` / `doodle_view_new` 接口）。

## 十、验收点

1. `meson setup builddir && ninja -C builddir` 通过；`./builddir/notework` 行为不变；新增 `./builddir/notework-doodle` 可独立运行。
2. 在画布上画 3 条直线 + 1 条路径，右侧列出 1/2/3/4。
3. 擦除路径中段，列表自动变为对应数量的路径项，编号紧凑且顺序保留。
4. 选中一条直线 → 阵列 2x3，间距任意 → 拖动预览 → 应用 → 列表新增 6 个连续编号；删除该组 → 编号回到擦除前的状态。
5. 在某项把编号手改为 100：右侧"缺号"区显示从最大编号倒推后的缺号区间；恢复后提示消失。
6. 点"在下方插入图片图层"：图层列表多一项 image-stub，画布渲染不变。
